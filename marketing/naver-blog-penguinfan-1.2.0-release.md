## 추천 제목

**맥북 팬 커브가 더 조용하고 편리해졌습니다, PenguinFan 1.2.0 업데이트**

## 대체 제목

- 첫 커브 포인트 전에는 macOS에 맡긴다, PenguinFan 1.2.0
- RPM 숫자 입력과 +/- 버튼을 추가한 무료 맥 팬 컨트롤러
- M2 Max 메뉴바 팬 앱 PenguinFan 1.2.0 정식 공개

무료 오픈소스 M2 Max 팬 컨트롤러 **PenguinFan 1.2.0**을 공개했습니다.
이번 업데이트는 저온 구간의 불필요한 강제 팬 제어를 줄이고, 수동 RPM을
더 정확하고 편하게 설정하는 데 초점을 맞췄습니다.

## 포인트 1 전에는 macOS 시스템 제어

![저온 시스템 제어 구간](images/penguinfan-1.2.0-system-zone.png)

기존 커브 모드는 현재 온도가 첫 번째 포인트보다 낮아도 포인트 1의 RPM을
계속 적용했습니다. 1.2.0부터는 **0°C부터 포인트 1 미만까지 앱의 강제 RPM
제어를 해제하고 macOS 시스템 자동 제어로 복귀**합니다.

따라서 낮은 온도에서는 macOS가 팬 정지 또는 저속 운전을 판단하고, 온도가
포인트 1에 도달하면 PenguinFan 커브 제어가 시작됩니다. 하드웨어 최소 RPM
아래에 0 RPM을 강제로 기록하지 않기 때문에 안전 범위도 유지합니다.

macOS가 위험 thermal pressure를 감지한 경우에는 저온 구간 설정보다 안전
동작이 우선하며, 기존과 같이 최대 지원 팬 속도를 요청합니다.

## 수동 RPM을 숫자와 버튼으로 설정

![수동 RPM 입력과 버튼](images/penguinfan-1.2.0-manual-controls.png)

수동 제어 화면에는 세 가지 입력 방법이 제공됩니다.

- 원하는 RPM 직접 입력
- `-50`, `+50` 버튼으로 미세 조절
- 기존 슬라이더로 빠르게 조절

어떤 방법을 사용해도 두 팬이 공통으로 지원하는 최소·최대 RPM 범위를
자동으로 적용합니다. 범위를 벗어난 숫자를 입력해도 안전 범위 안으로
조정됩니다.

## 더 넓어진 설정 창

설정 항목이 잘리지 않고 한눈에 들어오도록 기본 설정 창을 `760 x 680`
크기로 넓혔습니다. 최소 창 크기도 지정해 수동 RPM 입력과 온도 커브가 너무
좁게 압축되지 않도록 개선했습니다.

## 기존 안전 기능은 그대로

- 연결이 끊어지면 macOS 시스템 팬 제어로 복귀
- 6초 watchdog과 heartbeat 감시
- 팬별 하드웨어 최소·최대 RPM 검증
- 앱 경로, 코드 서명, Team ID, 로그인 사용자 검증
- `osascript` 관리자 암호창 없는 권한 분리 구조
